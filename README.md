# Packaging Engineering Tools Lab

一个尝试通过 Vibe Coding 快速解决身边实际需求的实验项目。

> 项目状态：已停止维护  
> 项目性质：Vibe Coding 实验 / 内部需求验证 / 失败项目复盘

## 项目背景

本项目来源于工作中观察到的一个实际需求：

包装工程相关工作中，存在一些重复、规则明确，但依赖人工操作的小任务。如果能够将这些操作转化为简单的网页工具，可能可以降低使用门槛，并减少重复劳动。

因此，本项目尝试使用 Vibe Coding 的方式，在不进行完整产品规划和传统软件开发流程的情况下，通过自然语言描述需求、快速生成代码、持续修改和调试，验证以下问题：

- 不具备完整软件工程团队的情况下，能否快速制作一个可用的小工具
- Vibe Coding 是否适合解决工作中零散、具体、规模较小的需求
- 包装工程中的部分规则，是否能够被转化为网页交互和自动计算
- 从发现需求到生成原型，是否可以显著缩短开发周期

本项目选择“规则纸箱结构绘制”作为切入点。

## 项目目标

项目最初希望实现一个简单的网页工具，使使用者能够通过输入参数，快速生成规则纸箱的基础结构。

主要尝试方向包括：

- 根据尺寸参数生成规则纸箱结构
- 调整纸箱长、宽、高等基础数据
- 在网页中实时预览结构
- 设置部分材质参数
- 导出生成结果
- 验证包装工程小工具网页化的可行性

项目的重点并不只是完成一个纸箱工具，也包括验证：

> Vibe Coding 能否成为解决身边小型工作需求的一种低成本方法。

## 开发方式

本项目主要采用 Vibe Coding 的方式完成。

开发过程中，并不是先编写完整的技术方案，再逐步实现，而是采用以下循环：

1. 用自然语言描述需要实现的功能
2. 由 AI 生成或修改代码
3. 在浏览器中运行并观察结果
4. 根据错误和实际效果继续调整需求
5. 重复生成、测试和修正
6. 逐步拼接出一个可以运行的原型

这种方式降低了开始开发的门槛，也使一个来自日常工作的想法能够较快变成可交互的网页。
